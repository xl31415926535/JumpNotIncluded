# 跳跃另购 · Jump Not Included

Unity 6.3（6000.3.24f1）二维平台游戏，当前版本 **v1.10.2**。两个短关卡，全部游戏界面与广告文字使用英文。正常游玩保持经典马里奥画面，死亡后才出现广告与购买页。

## 直接运行

运行 `Builds/Windows/JumpNotIncluded.exe`，选择 **1 PLAYER GAME → START**。压缩包需完整解压，保留 exe 旁的数据目录。

在 Unity 中：

1. Unity Hub → Projects → Add project from disk，选择本文件所在的 `JumpNotIncluded` 文件夹。
2. 使用 **6000.3.24f1** 打开，等待导入完成。
3. 选择 **Tools → Jump Not Included → Play from MainMenu**，或打开 `Assets/Scenes/MainMenu.unity` 后点击 Play。
4. 更新后从主菜单重新开局。旧 Play Mode 中的运行对象不会自动变成新版。

资源自动升级到 revision 9，保留已有 GUID。Input System 1.20.0 已嵌入本地 Packages。

## 操作

- A / D、左右方向键：移动。
- Space / W：跳跃；购买前只播放短促拒绝音。购买帝王之翼后在空中再按一次可二段跳，落地恢复次数。
- J：火焰形态 / VIP 发射火球；持有加特林时按住连续射击，小马里奥也能使用。
- Esc：暂停；从充值页先回商品页，再按一次恢复游戏。
- 菜单支持鼠标、上下方向键选择、Enter 确认。音乐和音效有独立开关。

## 现金、金币和商店

**广告现金**上限 $99.00。死亡后打开商品页，点击左上角金币旁的 **＋** 进入充值页。现金用来兑换金币，商品使用金币支付：

- $1.00 → 100 金币。
- $9.80 → 1,000 金币，较基础档便宜 2%。
- $18.80 → 2,000 金币，较基础档便宜 6%。

地图每枚金币增加 **1 个可消费金币**，同时增加 100 分。积分与货币独立，消费不会扣除积分。

六种商品均在本局内有效：

- **Jump DLC · 199 金币**：解锁基础跳跃。
- **Fire Flower · 299 金币**：购买立即进入 Fire Mario，更新碰撞体与检查点；两关地图都没有花朵。
- **Mushroom ID · 1299 金币**：当前及后续关卡所有毒蘑菇都变为普通蘑菇，恢复正常颜色和成长效果。
- **Master Guide · 1999 金币**：提前显示暗砖和隐藏奖励位置，仍需撞击或射击才能领取。
- **Monarch Wings · 2999 金币**：基础跳跃加一次空中跳跃；未买 Jump DLC 也能直接使用。已经拥有基础跳跃时不会退款抵扣。
- **Gatling · 5999 金币**：持续平射并清理前方 14 格，拆除暗砖、普通砖、管道，清除毒蘑菇、敌人和库巴火焰，填平缺口。买后按住 **D＋J** 即可沿平路通关，不需要跳跃或其他升级。

第二关购买页可退订火焰花，按原订单实际支付的**金币**退回；当前 Fire 降为 Super，火球资格收回，加特林仍独立可用。现金已满 $99 不会妨碍金币退款。

示例：看满两秒获得 $2，兑换两次 100 金币，买跳跃后剩 1 金币；再看三秒、兑换三次后买火焰花，剩 2 金币。第一关奖励 $4、第二关补贴 $6；用 $9.80 换 1000 金币，再退火焰花得 299 金币，即有 1301 金币，可买蘑菇鉴别并剩 2 金币与 $0.20。

## 广告与形态

- **REVIVE - 2 SECOND AD**：观看满两秒回到检查点，不奖励现金。
- **EARN CASH - $1 / SEC**：每完整一秒获得 $1，可随时 **STOP & KEEP CASH**；不足一秒不计奖，可重复观看。达到 $99 自动结束，兑换后可继续观看。
- 广告失焦停表。Mario、SUTD/AI、SL Cheater 每组三支随机洗牌，各出现一次，跨组不连续重复。赚钱广告每五秒换片，复活广告只播一支。
- SUTD 官网宣传图片与 SL Cheater 武神立绘本地打包，离线可看。每次只出现一个活动面板；免费重试始终可用。
- 敌人和毒蘑菇伤害按 **Fire → Super → Small → Dead** 逐级处理。每次降级保护 1.5 秒；碰撞体变高或变矮时保持脚底位置。坠落始终致命。
- 第二关死亡购买页提供一次八秒 VIP：无敌、加速、临时火球和蘑菇安全。普通星星独立持续六秒。世界暂停时强化计时也暂停。

交易与广告均为本地模拟，没有真实付款或广告 SDK。

## 重试与保存

- 检查点重试恢复最近快照的积分、金币、现金、订单、授权、形态、已领取奖励和已击败敌人；死亡次数、广告记录与累计时间保留。短时强化与飞行物清除。
- 已经进入快照的暗砖保持显现；被击碎的砖、拆除的管道和已击败的库巴不会重新出现，填平的路保持存在，奖励不能重复领取。
- 隐形检查点位于第一关 26 / 60 格、第二关 34 / 80 格，经过并落地保存。未到检查点的关卡进度会回退，已经花费的广告与操作时间不会回退。
- 兑换、购买、退款及广告现金入账后保存，货币与能力一起恢复。死亡进入商店时先回到安全检查点。
- 完整重开清除本局两种余额与所有能力，保留最高分及音量选项。下一关保留余额与能力。
- 最高分和音量使用 PlayerPrefs；主菜单可清除最高分。检查点只在当前游戏运行期间有效。

## 工程结构与验证

- `RunModel / RunState`：纯 C# 经济规则、ScriptableObject 本局数据和快照。
- `PlayerFormController / BuffStateController`：六种角色状态与三种强化状态；SO 定义 State / Decision / Action。
- `GameEvents`：击杀 → 计分 → UI 的事件通知。
- `AudioDirector`：Music / WorldSFX / UI_Ads 独立音源与 Mixer 分组，购买页低通处理。
- `BlockActor / BossActor / BossFlame / Fireball`：暗砖、强敌和两类射击。
- 不使用 Singleton 或 DontDestroyOnLoad 管理器。

Unity **6000.3.24f1** 的 **145 项实际 Play Mode 检查已通过**。覆盖朝向、砖块、音源、逐级伤害、广告计时与轮播、兑换退款、暗砖、星星、引导、二段跳、持续穿透射击以及库巴。新增验证广告零头秒数、失焦／暂停不计时、计时跨重试和关卡保留、结算停表、重新开局清零、库巴群独立击败存档。板栗新增验证越过旧边界、原地玩家被实际接触致死、管道转向、踩踏、镜头激活、暂停和掉坑。无敌星音乐验证实际拾取切曲、播放推进、暂停续播、再次拾取不重启、自然到期续播关卡曲目、死亡停止以及第二关静音保持。真实输入连续通关：只购买加特林，始终按住 D＋J，击败全部 10 只库巴，依次完成两关且没有新增死亡。
