# 跳跃另购 · Jump Not Included

Unity 6.3（6000.3.24f1）二维平台游戏，当前版本 **v1.14.1**。两个短关卡，全部游戏界面与广告文字使用英文。正常游玩保持经典马里奥画面，死亡后才出现广告与购买页。

## 直接运行

使用已构建的 Windows 包时，运行 `Builds/Windows/JumpNotIncluded.exe`，选择 **1 PLAYER GAME → START**。压缩包需完整解压，保留 exe 旁的数据目录。GitHub 源码仓库不包含生成的 exe，可按下文在 Unity 中运行或构建。

在 Unity 中：

1. Unity Hub → Projects → Add project from disk，选择本文件所在的 `JumpNotIncluded` 文件夹。
2. 使用 **6000.3.24f1** 打开，等待导入完成。
3. 选择 **Tools → Jump Not Included → Play from MainMenu**，或打开 `Assets/Scenes/MainMenu.unity` 后点击 Play。
4. 更新后从主菜单重新开局。旧 Play Mode 中的运行对象不会自动变成新版。

资源自动升级到 revision 12，保留已有 GUID。Input System 1.20.0 已嵌入本地 Packages。

## 操作

- A / D、左右方向键：移动。
- Space / W：跳跃；购买前只播放短促拒绝音。购买帝王之翼后在空中再按一次可二段跳，落地或踩怪反弹恢复次数。机甲模式改为按住推进升空、松开悬停。
- S / 下方向键：机甲模式下降，可落在地面或水管顶并关闭推进器；深坑下方自动触发悬停保护。
- J：火焰形态 / VIP 发射火球；持有加特林时按住连续射击，小马里奥也能使用。机甲模式按住自动锁定敌人，释放秒杀激光。
- Esc：正常游玩时暂停；充值内页先返回礼包选择，再返回商品页，再返回死亡页。不能跳过复活广告。处理中的付款会取消。
- 菜单支持鼠标、上下方向键选择、Enter 确认。音乐和音效有独立开关。

首次机甲登场期间暂不接受上述游玩操作或界面跳过；观看完整动画后恢复正常控制。

- **REVIVE - 2 SECOND AD**：死亡后从检查点继续的必要步骤，必须在有焦点时观看完整两秒，不奖励现金。
- **EARN S$1 / SEC**（充值页为 **EARN SGD**）：每完整一秒获得 S$1，可随时 **STOP & KEEP CASH**；不足一秒不计奖，可重复观看。达到 S$99 自动结束，付款后可继续观看。
- 广告失焦停表。Mario、SUTD/AI、SL Cheater 每组三支随机洗牌，各出现一次，跨组不连续重复。赚钱广告每五秒换片，复活广告只播一支。
- SUTD 官网宣传图片与 SL Cheater 武神立绘本地打包，离线可看。每次只出现一个活动面板；赚钱广告不替代复活广告。
- 未装备机甲时，敌人和毒蘑菇伤害按 **Fire → Super → Small → Dead** 逐级处理。每次降级保护 1.5 秒；碰撞体变高或变矮时保持脚底位置，坠落致命。机甲免疫原版怪物及其攻击，坠入悬崖会自动悬停。
- 第二关死亡购买页提供一次八秒 VIP：无敌、加速、临时火球和蘑菇安全。领取后先看复活广告，完成后才激活八秒效果。普通星星独立持续六秒。世界暂停时强化计时也暂停。

交易与广告均为本地模拟，没有真实付款或广告 SDK。

## 重试与保存

- 检查点重试恢复最近快照的积分、金币、现金、订单、授权、形态、已领取奖励和已击败敌人；死亡次数、广告记录与累计时间保留。短时强化与飞行物清除。
- 机甲登场完成后才设置并保存 `RunModel.mechDeployed`；同局检查点恢复与换关保留完成状态，未完成的登场在恢复后重新播放，`NewRun` 清除完成标记。
- 已经进入快照的暗砖保持显现；被击碎的砖和已击败的库巴不会重新出现，奖励不能重复领取。当前加特林不会改变水管或缺口。
- 隐形检查点位于第一关 26 / 60 格、第二关 34 / 80 格，经过并落地保存。未到检查点的关卡进度会回退，已经花费的广告与操作时间不会回退。
- 充值、购买、退款及广告现金入账后保存，货币与能力一起恢复。绑卡与解绑也保存。死亡进入商店时先回到安全检查点。
- 完整重开清除本局两种余额与所有能力，重置虚拟卡额度和交易记录，保留最高分及音量选项。下一关保留余额、能力与支付账户。
- 最高分和音量使用 PlayerPrefs；主菜单可清除最高分。检查点只在当前游戏运行期间有效。

## 工程结构与验证

- `RunModel / RunState`：纯 C# 经济规则、ScriptableObject 本局数据和快照。
- `PaymentAccount`：绑卡、额度、两种支付来源、金额校验、防重复订单及收据。
- `SceneRoot.Payment / GameUI.Payment`：充值步骤、确认与取消、处理进度、SGD 界面和交易记录。
- `PlayerFormController / BuffStateController`：六种角色状态与三种强化状态；SO 定义 State / Decision / Action。
- `GameEvents`：击杀 → 计分 → UI 的事件通知。
- `AudioDirector`：Music / WorldSFX / UI_Ads 独立音源与 Mixer 分组，购买页低通处理。
- `BlockActor / BossActor / BossFlame / Fireball`：暗砖、强敌和两类射击。
- `MechArt / MechSuit / MechExhaust / MechPixelLaser / MechArrival / GameUI.Mech`：六帧像素机甲、16 PPU 三色喷流与阶梯激光，行走／推进／悬停／落地、独立音源、像素意识接入与钱包直购展示页。
- 不使用 Singleton 或 DontDestroyOnLoad 管理器。
