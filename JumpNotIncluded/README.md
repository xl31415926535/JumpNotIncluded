# Jump Not Included v1.10 preserved snapshot

This is a source snapshot imported during repository preparation. Open this
directory using Unity 6000.3.24f1 and select Tools > Jump Not Included > Play from MainMenu.

A/D or arrow keys move; Space/W jump after unlocking Jump or Monarch Wings;
J fires when the appropriate upgrade/form is active; Esc pauses.

The saved baseline contains the known Goomba patrol-boundary, mushroom sprite,
and Star music issues. Later repository commits apply the corresponding fixes.
The source was not originally committed when developed; see the root README.
