# War God pixel redraw — v1.14.0

Generated with the built-in imagegen tool from the existing War God flight sheet, the game's Mario sheet and a v1.13.1 hover capture. The generated PNG is preserved unchanged as `war-god-8bit-v1.png`.

Unity samples a 52 × 52 grid inside each of the six cells, clips soft transparent edges and maps the result to a small flat palette. `MechArt` supplies pose-specific foot anchors, rendering at 16 logical pixels per world unit. The original image-generation result did not precisely follow the requested grid or baseline; the runtime mapping corrects those differences.

## Prompt submitted

Use case: style-transfer. Asset type: production 2D game sprite atlas with transparent background. Redraw the winged black-and-silver WAR GOD mech from reference 1 so it belongs visually in the original 8-bit Super Mario Bros game (reference 2 is the pixel-art style target, reference 3 shows the scale problem in the game). Preserve recognizable angular helmet, silver armor on black joints, small cyan visor/reactor, two mechanical folded/open wings, boots. Replace the fine metallic details with bold simple 8-bit pixel clusters. The character must look like a genuine NES-era 32-pixel-tall game sprite, approximately the height of big Mario, NOT a high resolution detailed illustration or modern pixel art. Limited palette: near-black/navy outline and joints, flat medium blue-gray armor shade, flat light gray armor highlights, white highlights, cyan accents, tiny gold core. No gradients, no antialiasing, no dither, no tiny metal filigree. Crisp square grid pixels with deliberate stair-step edges. No smooth light glow. Full transparent background, no cast shadows, no text or labels, no grid lines. EXACT ATLAS LAYOUT: output 1536x1024 pixels, 3 columns by 2 rows of equal 512x512 cells. Each cell is an exact nearest-neighbor 8x enlargement of a logical 64x64 sprite cell. ALL six mech sprites face RIGHT in side profile, consistent body scale and helmet/torso/boot design, same foot baseline at logical y=52 in each cell (actual y=416 within cell), body center logical x=34 (actual x=272). Main helmet-to-boots height is exactly 32 logical pixels; wings may extend left to logical x=9. Keep ample transparent margins. Top row: 1 ground idle with folded wings, feet planted; 2 walking right left leg forward; 3 walking right right leg forward. Bottom row: 4 vertical hover, both wings completely unfolded to the left, legs extended down, boots visible; 5 forward flight with unfolded wings, body leaning only slightly right, feet visible; 6 alternate forward-flight wing pose, same body. IMPORTANT: absolutely NO exhaust/jet/flame/wake lines or particles in ANY sprite; these are rendered independently in the game. The exposed underside of both boots should be clearly readable as nozzles. Shape and color should match the chunky simple pixel scale of Mario, while remaining this mech. Produce only this usable atlas, not a comparison sheet or concept board.
