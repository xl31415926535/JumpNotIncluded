# Jump Not Included

Unity 6000.3.24f1 platform game. Open the `JumpNotIncluded` subfolder in Unity Hub,
then use **Tools > Jump Not Included > Play from MainMenu**.

This commit imports the preserved v1.10 validation snapshot. Development before
this publication did not have Git commits. These commits are being recorded now
from surviving source snapshots and known fixes; their dates are publication
dates, not the original dates of development. The remote initial commit is kept.

The snapshot already contains two worlds, the death screen and restart,
advertisements, two currencies, six upgrades, hidden blocks, ten opening Bowsers,
and itemized victory receipts. It still has the fixed Goomba patrol boundary and
the mushroom/Star music issues addressed by subsequent commits.

The historical 126-check runtime report is in `verification/history/v1.10-runtime-checks.txt`.
Source hashes and import exclusions are recorded in `verification/history/source-manifest.json`.
The embedded Input System package is included, with its upstream license.
