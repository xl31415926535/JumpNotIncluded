# v1.10.1 Goomba movement fix

The user reported that the opening Goomba turned at an invisible wall instead
of reaching the player. The preserved baseline supplies fixed min/max patrol
coordinates (`Enemy(14,11,16)`); the fix removes them and casts against terrain.

This intermediate source stage is reconstructed from the saved baseline and the
preserved final Goomba changes. It is not claimed to be an independently retained
complete v1.10.1 archive. The reconstruction excludes the later Star audio changes.

Changed files: EnemyActor.cs, WorldBuilder.cs, RuntimeChecks.cs. Ten regression
checks cover crossing the former boundary, killing idle Small Mario by contact,
camera activation, pause, actual pipe reversal, stomping and falling into gaps.

The retained packaging script explicitly requires 136 passing checks. The local
historical Unity runtime log contains `ALL RUNTIME CHECKS PASSED`; the build log
contains `JNI Windows build succeeded.` The complete per-check 136-result report
was overwritten by the later 145-result run and is not reproduced as an original
report here. Baseline and final reports are preserved separately.

Packaging scripts under tools/history are historical evidence, not commands to
run against the current revision: their old revision/check-count assertions are
intentional. Original development occurred before these publication commits.
