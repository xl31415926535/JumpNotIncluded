## 1. 核心体验

一个开场看起来正常的马里奥，按跳跃只有错误提示音。第一次死亡才揭露“经典功能另购”的广告与商店。玩家通过绑定虚拟信用卡，用新加坡元购买金币和能力；也可以看广告获得 SGD 钱包奖励。最高价的 SL Cheater 武神仿制机甲直接消费广告钱包，以免伤、飞行与自动锁定激光体现付费碾压。

普通游玩只显示 MARIO 分数、金币、WORLD 和 TIME，不放商业通知、客服终端、购买入口或促销倒计时。死亡冻结世界，之后每次只显示一个活动面板。死亡页不再提供免费重试、关闭叉或底部原说明；从检查点继续必须观看完整两秒复活广告，完整重开则清空本局数据。

主菜单保留 SUPER MARIO BROS. 招牌，下方以小字显示 Jump Not Included；右侧的黄色红边爆炸框写 FREE TO PLAY，与随后揭露的付费能力形成反讽。标牌不遮挡标题、HUD 或开始按钮。

全程模拟交易，无真实付款、广告 SDK 或账号服务。所有游戏文案采用英文，设计文档采用中文。

## 2. 当前完整范围

主菜单、加载场景、两个短世界、死亡页、随机广告、六种金币升级、独立机甲展示与钱包直购、首次部署动画、结算收据。基础玩法包括走跳、踩怪、问号箱、空砖、隐藏砖、金币、普通与毒蘑菇、无敌星、形态受伤、火球、库巴、加特林与机甲。

大师引导、帝王之翼、加特林与机甲均为可购买、可使用的功能。v1.12.0 降低翅膀和加特林价格，取消加特林拆水管及填坑，把跨越地形和免伤优势交给机甲。

## 3. 操作与手感

- A/D 或左右方向键移动，速度 5.5 格/秒。
- Space/W 跳跃，初速度 17 格/秒，松开降低跳高。
- 离开地面后 0.12 秒内仍可起跳；落地前 0.12 秒按键可缓存跳跃。
- J 发射火球；持有加特林时按住连发，机甲模式按住自动锁定并发射秒杀激光。
- 帝王之翼的空中追加跳跃在落地或踩怪反弹后恢复一次。机甲模式下 Space/W 改为按住推进升空、松开悬停；S/下方向键下降，接触真实地面或水管顶后收翼并停止喷流与引擎。
- Esc 暂停或关闭购买页。UI 支持鼠标、方向键和 Enter。
- 小形态约一格高，大/火形态约两格高；变形使用刚体物理位置保持脚底高度。

## 4. 第一关：熟悉感、广告与暗砖

长度约 96 格，隐形检查点在 26 / 60 格，必须落在地面才保存。

### 开头与成长

蓝天、管道、Goomba 和经典 HUD。跳跃未购时只响短促音，不弹文字，也不重启 BGM。第一只敌人制造第一次死亡后的商业揭露。

板栗不使用固定坐标巡逻边界：进入镜头后朝左行走，遇到实际管道或砖块才反向，走出地面会掉落；激活后离开镜头仍会继续移动。开头的板栗能走回出生点，玩家即使原地不动也会被碰到，未受保护的小形态会死亡。后段尚未进入镜头的板栗等待激活，避免提前离开设计位置。

背景交替使用原图的小山与大山，保持每格 16 像素的比例。山脚对齐地面，整段山体底边都放在陆地范围内，悬崖区域不生成悬空山体。

第一关 44 格之前没有暗砖，避免过早泄露套路。22 格的问号箱提供普通蘑菇。成长蘑菇使用红色贴图，吃下后变大，不再误用绿色加命蘑菇。两关均不放置火焰花，购买后直接获得 Fire。

### 悬崖陷阱

地面在 44–50 格断开，宽 6 格。悬崖上方设置两层、共 8 块暗砖：下层位于 44.5 / 45.5 / 46.5 格，高 2.6 格；上层位于 44.5–48.5 格，高 4.9 格。

- 从悬崖边约 43.5 格起跳，头顶触发暗砖，中止上升后掉进悬崖。
- 约 42.8 格提前起跳也会撞到上层暗砖，首次接触时更容易坠落；把第一条看似合理的补救路线也变成陷阱。
- 只有上升时从底面进入才显现。侧面或下降穿过不会触发，未显现砖也不算地面。
- 购买大师引导后可以提前看到轮廓与奖励；帝王之翼可提供空中补救；加特林清掉前方暗砖但保留悬崖，机甲可从空中越过并在坠落时自动悬停。

46.5 格上层暗砖及 70 格暗砖提供六秒无敌星，其余悬崖暗砖和 82 / 84 / 86 格暗砖提供金币。可见金币诱导玩家向缺口起跳；原 49 格的毒蘑菇移到 51 格的对岸。

无敌星生效期间用音乐声道循环播放 `05-starman.mp3`，替换当前关卡 BGM；效果结束后续播被中断的关卡曲目。重复拾取星星刷新效果时长，不重启音乐。暂停同时冻结音乐和无敌倒计时，音乐静音开关对无敌曲同样有效，死亡与结算停止播放。

通关奖励 S$4 现金。加载下一关前由玩家点击 START；积分、现金、金币与能力跨关保留。

## 5. 第二关：库巴与能力展示

长度约 112 格，隐形检查点在 34 / 80 格，避开开头的库巴群和后段的密集障碍。进入时发放本局一次性的 S$6 现金补贴，不在正常 HUD 弹提示。

开头堆放 10 只库巴，中心从 8 格到 29.6 格，每只在出生点左右 0.7 格巡逻。每只 18 点生命，首轮喷火逐只错开 0.18 秒，近距离瞄准玩家。开火前短暂变色，受击闪烁，受伤后显示血条。

- 火球与有效踩踏各扣 1 点生命；侧面接触按角色形态造成伤害。
- 加特林前方 14 格的清场范围可以立即清除库巴，不需要磨掉整条血。
- 无敌星或 VIP 接触直接击败。机甲免疫库巴和喷火伤害，锁定激光直接秒杀。
- 子弹可消除喷出的火焰。敌人与火焰均随暂停停止。
- 每只击败奖励 1500 分，并掉落一枚普通金币；独立标记确保只移除已经击败的库巴，奖励不会共用或重复发放。

21 格隐藏无敌星、23 格隐藏金币。36–69 格每隔 2.2 格布置一只板栗，中间夹毒蘑菇；悬崖前再放一组，82–105.1 格用每隔 2.1 格的队列继续压迫。整关合计 29 只板栗、31 个毒蘑菇。第二关死亡商店提供火焰花退款和一次八秒 VIP。

终点不追加付费通关门槛。两关结算均使用三栏收据：广告观看秒数、购买金币总额、亲自操作秒数，另列机甲直购花费的 SGD 钱包金额，不把新元与金币相加。最终标题为 “VICTORY, ITEMIZED.”，以 “Congratulations. Your purchasing power has defeated the game.” 收尾；没有购买时使用对应的无消费文案。

广告时间累计实际观看的小数秒，即使该零头未产生奖励也计入；失焦或广告已经自动结束的部分不计。操作时间只累计游戏进行中、窗口有焦点时的移动／跳跃／射击输入；一次同时按多个键只算一次时间。退款和净支出另列。时间条比较广告、操作及关卡内闲置，占比不包含菜单和购物。两类时间保留所有失败尝试，跨检查点和换关累计，重新开局清零。

## 6. SGD 充值、金币与升级

SGD 钱包用整数分保存，上限 9900 分，即 S$99.00。虚拟信用卡拥有独立的每局 S$99.00 额度，按分扣减。金币用整数独立保存；每个地图金币增加 1 金币、100 积分。消费金币不扣积分。机甲只从 SGD 钱包扣除 7999 分，金币和虚拟卡均不能用于这笔购买。

SGD 礼包固定为：

- S$1.00 → 100 金币。
- S$9.80 → 1000 金币，较基础档便宜 2%。
- S$18.80 → 2000 金币，较基础档便宜 6%。

商品页左上角显示金币余额和金色加号；点击加号进入独立 JNI / PAY 页面。三张礼包卡展示金币、SGD 价格和优惠，右侧显示订单总额及零手续费。顶部保留金币余额、三步进度和模拟交易标记。六种金币能力留在商品页，底部入口打开机甲独立展示页。

默认路径为选择礼包 → 绑定虚拟卡 → 核对金额 → 确认付款 → 处理进度 → 完成收据。卡片由游戏生成，只显示尾号 3141；不输入真实卡号。绑卡不扣款。核对页明确显示总价和可用额度，额度不足禁用付款。确认后处理 1.4 秒，失焦时暂停。处理期间可取消或关闭，未完成交易不扣款；不能插入赚钱广告打断支付。

玩家也可选择 SGD WALLET；广告每完整一秒增加 S$1，结束后回到充值页。只有被选中的付款来源被扣减。余额不足、无效礼包、金币溢出均整笔拒绝；独立订单号防止重复确认或回调导致重复扣款。扣款、到账和收据在同一次提交中完成，并立即保存检查点。

收据显示订单号、UTC 时间、支付方式、SGD 金额、到账金币、当时的金币余额及剩余额度／钱包余额。交易记录每页六条，可回看原始收据。绑定、消费和收据跨死亡与关卡保存，解绑再绑卡不刷新额度；完整重开才清空。Esc 从内页退回礼包选择，再退回商品页，再返回死亡页；X 只关闭充值回商品页。所有浏览与支付步骤保持世界暂停，不能免除复活广告。

### 推销语气

游戏内商品、广告和充值文案使用故意夸张的英文宣传，围绕神授、革命、超越物理和必然胜利，而不是解释“基础功能”。例如跳跃宣称引入新维度、摆脱平地暴政；帝王之翼宣称是古老圣巢与苍白之王的神圣遗产；加特林强调压倒性的前方火力。机甲突出 **STARFIELD CAMOUFLAGE、MOON KILLER、1% LIGHT SPEED**，把星空迷彩、月球杀手与加速到百分之一光速作为讽刺广告神话；实际移动仍按可玩的关卡尺度处理。金币金额、SGD 金额、广告秒数、返回按钮和模拟交易说明保持准确。

### 最高价机甲的体验

首次购买机甲并完成两秒复活广告后，进入 **6.2 秒不可跳过的部署动画**。世界与角色控制冻结，机体像降落火箭一样从天而降，在玩家附近用鞋底朝下的青白像素反冲减速至悬停；马里奥化为离散像素流光，沿接入轨迹投入机甲核心。核心完成同步后恢复机体控制。登场与正常机体使用相同六帧图集的第 3 帧展翼姿势，显示比例为 1，保持有效 16 PPU；地面扬尘、核心提示与扫描线均为离散像素块。叙事解释为意识接入，不使用生物脑移植、解剖或血腥意象。

三段屏幕标题均为英文：**ORBITAL DELIVERY → CONSCIOUSNESS UPLINK → SYNCHRONIZATION COMPLETE**。火焰、推进声与流光同步，完成后衔接普通机甲表现。Esc、Space、J、Enter 和任何界面操作不能跳过。窗口失焦暂停动画计时和声音，聚焦后接续；登场时间不计入 `playTime`、`activeInputTime` 或广告观看时间。

每局只在首次部署时播放。只有完整结束才设置并保存 `RunModel.mechDeployed`，同局检查点恢复、场景重载与换关保留该完成标记；动画中断而未完成时，恢复后重新播放。`NewRun` 清除标记、授权与本局其他数据。购买与原有两秒复活广告的先后规则保持不变，登场动画不替代复活广告。

登场完成后，无需购买跳跃或帝王之翼：按住 Space/W 启动推进器升空，松开后保持当前高度，S/下方向键下降。向下移动可真正落在地面或水管顶部，着地后停止喷流与引擎循环声。最低悬停高度只作为悬崖保底，不覆盖真实地形的落脚高度。按住 J 自动选择敌人，显示锁定与激光并立即消灭目标；库巴等原版怪物及其攻击无法损伤机体。水管与地面缺口保持原貌，机甲售价、攻击和免伤规则保持不变。

机甲依据 SL Cheater 武神设计重绘为六帧 8-bit 动作图，保留黑银装甲、青色灯线、金色核心与折叠翼。每帧按 52 × 52 个逻辑像素采样，经有限色板材质显示为有效 16 PPU，与马里奥和地形的像素颗粒一致；原始 PNG 分辨率不被当作游戏中的有效像素密度。地面静止使用第 0 帧收翼姿势，地面行走交替第 1–2 帧，均无喷流和引擎循环声；垂直升空与悬停使用第 3 帧，空中横向移动交替第 4–5 帧。

垂直喷流与水平尾迹独立于图集：均由 1/16 世界单位的不透明方格组成，只使用白、青、蓝三色，没有平滑渐变。升空与悬停时垂直喷流向下；横向巡航额外开启朝行进反方向的水平尾迹；落地全部关闭。喷口按新六帧姿势的鞋底与后部锚点定位。原 SL Cheater 立绘、动画图集和音效继续保留为来源、展示和旧版本资料，当前角色与登场使用新重绘图。

激光仍自动锁敌并秒杀，视觉改为沿像素格行进的阶梯路径，命中闪光与余辉分帧切换有限色块。推进器点火、持续推进和激光使用独立音源并接入 WorldSFX，真正着地停止引擎，暂停、失焦和离开游玩状态时停止或暂停对应声音，不反复触发点火或重启 BGM。本次不改变 S$79.99 价格、交易、飞行、落地、保护、攻击、登场时长或存档行为。

加特林保留清敌和拆砖优势，越过水管与悬崖需结合跳跃或机甲；旧版单按 D＋J 铺路通关的承诺已取消。

退款只对第二关的火焰花开放，退回订单实际支付的金币。当前 Fire 降为 Super，火球资格收回；独立加特林不受影响。现金满额不影响金币退款。每张订单只退一次，再次购买会产生新订单。

### 示例经济路线

1. 看两秒赚钱广告得 S$2，换 200 金币，购买跳跃剩 1 金币。
2. 再看三秒得 S$3，换 300 金币，购买火焰花剩 2 金币。
3. 第一关奖励和第二关补贴合计 S$10，兑换 S$9.80 档后剩 S$0.20、1002 金币。
4. 退花得 299 金币，购买 1299 金币的鉴别后剩 S$0.20、2 金币。

玩家也可保留花、先买高价能力或继续看广告。六种金币能力合计 **6794 金币**；兑换没有本局次数上限。地图拾取是额外收入，基础通行不依赖把所有金币找齐。

机甲独立路线：从零看满 **80 秒赚钱广告**得到 S$80，直接花 S$79.99 买机甲，余额 S$0.01。赚钱广告不代替死亡后的 **2 秒复活广告**。机甲金额和金币购买合计分别保留，不使用金币换算掩盖其成本。

## 7. 广告

复活广告固定两秒，是每次死亡后从检查点继续的必要步骤，不奖励现金。未满两秒不能提前完成，失焦不计时，Esc 不跳过。关闭商店返回死亡页，购买或充值不免除复活要求；商店主按钮也进入复活广告。赚钱广告每完整一秒发 S$1，可随时结束；零头不计，现金封顶自动返回商店，仍需观看独立的复活广告。失焦停止计时与轮播。

Mario、SUTD/AI、SL Cheater 三组广告使用随机洗牌，每组各出现一次，跨组不连续重复。赚钱广告每五秒换片但累计计时与金额不断；复活广告保持一支到结束。重试保留轮播历史，完整新开一局重建顺序。

SUTD 使用官网宣传图，SL Cheater 使用用户项目的武神立绘，本地打包离线展示。死亡页、广告和购买页统一为深蓝渐变、金色按钮、角色海报与奖励卡；无连续强制弹窗。

## 8. 形态与临时强化

未装备机甲时，普通伤害顺序为 Fire → Super → Small → Dead。每次降级保护 1.5 秒，重复接触不能一次跨过多种形态；毒蘑菇使用同一规则，坠落致命。装备机甲后，原版怪物及其攻击不能造成这些降级，悬崖保护使机体保持悬停。

角色 SO 状态机包含 Small、Super、Fire、HurtGrace、HurtSuperGrace、Dead；对外形态在保护期间仍对应 Small 或 Super，检查点不会保存一个无法恢复的过渡形态。

独立 Buff SO 状态机包含 None、Star、VIP。星星六秒无敌；VIP 八秒无敌、1.25 倍移速、临时火球和毒蘑菇安全。领取 VIP 后先看复活广告，结束后才激活并保存领取状态，后续死亡不能重新恢复这次试用。只计算实际游玩时间，暂停和购买期间停表，状态进入与结束有独立音效。

## 9. 保存、事件和声音

RunModel 管理纯规则与机甲钱包直购，PaymentAccount 管理金币充值的支付来源、额度、校验和收据；SceneRoot.Payment 管理充值状态转换，GameUI.Payment 绘制界面，GameUI.Mech 提供机甲展示。RunState 用 ScriptableObject 保存当前局与检查点。快照同时包含两种货币、支付账户、积分、形态、订单、授权及已领取/击败标记，机甲 SGD 消费与金币订单分别累计。已保存的暗砖不会重新隐藏，被击碎的砖和击败的库巴不会重复出现；当前加特林不修改管道与地面缺口。未到检查点的地图进度仍可回退。

广告入账、兑换、购买和退款后保存。完整重开清除本局数据，最高分及音量通过 PlayerPrefs 保留；换关保留两种余额和能力，清除临时强化。

`RunState.reviveRequired` 与死亡原因保存在检查点 JSON 之外，避免恢复旧快照时清除复活要求。死亡设置要求，复活广告完成后解除；场景加载和 `SetMode` 都遵守此状态。`NewRun` 重置要求并清空本局，不能用于保留死前进度。

`RunModel.mechDeployed` 区分已购买授权与已完成登场：付费时保存授权，动画完整结束后才保存部署完成标记。恢复场景或检查点时，已购买但未完成部署的机甲仍需播放登场；已完成部署不重播。部署期间阻止恢复 Playing、角色输入与界面跳过，不累计游玩和操作时间，失焦暂停专属声音与演出进度。

Input System 有 Gameplay / UI 两套映射；事件链使用 C# events / delegates 通知击杀、计分、UI 和音效。AudioMixer 分 Music、WorldSFX、UI_Ads 三组，音乐与音效各有开关。短音使用 PlayOneShot，跳跃失败不会重启循环 BGM。商店和广告对音乐使用低通处理。

没有 Singleton 或 DontDestroyOnLoad 管理器。WorldBuilder 构建地图，BlockActor、BossActor、BossFlame 和 Fireball 负责对应实体；MechArt 定义六帧像素姿势与可见范围；MechSuit 管理机甲动画、推进、悬停、落地与攻击；MechExhaust 绘制独立三色像素喷流，MechPixelLaser 绘制阶梯激光，MechArrival 管理像素意识接入演出。

## 11. 五次 Lab 的验收计划

以下是逐项开发目标，不是已完成声明。课程允许类似功能，但最终以教师验收为准。

### Lab 1

- 展示移动、跳跃、敌人接触与得分基础。
- 接触敌人触发 Game Over，画面中的世界物体停止移动，显示积分和 Restart。
- 完整重开回到初始关卡状态；两秒广告后的检查点复活另外展示。
- 保持 Console 清洁，整理文件和 Hierarchy。

对应场景：第一关开场与死亡界面。[官方验收说明](https://natalieagus.github.io/50033/docs/newborns/checkoff/)

### Lab 2

- 问号箱：仅下方顶击有效，闪烁、弹跳、出金币动画与音效，使用后换外观并失效。
- 砖块：仅下方顶击弹跳一次，含金币和空砖两种，金币音效完整。
- 从顶部与侧面接触，确认不会误触发。

对应场景：第一关中段的两类砖块；额外商店交互不替代它们。[官方验收说明](https://natalieagus.github.io/50033/docs/babies/checkoff/)

### Lab 3

- Input System 实际接管操作与 UI。
- 用 Events / Delegates 的 Observer 通知击杀和计分；跳过敌人不加分。
- 所有声音接入 Mixer 分组；演示商店低通滤波，并解释用途。
- 录屏收录声音，展示 Mixer 与 Inspector。

对应场景：踩怪、积分更新、商店开关。[官方验收说明](https://natalieagus.github.io/50033/docs/toddlers/checkoff/)

### Lab 4

- 暂停 / 恢复、强化、敌人死亡和 Game Over 具有明确音效。
- 主菜单、可返回主菜单的加载场景、两个世界。
- 当前积分跨世界保留；最高分停止运行后仍在，菜单可以清除。
- 至少两种可交互强化，并验证拾取方向。
- 完整重开复位敌人、道具、音乐和本局积分；展示 SO 用法。
- 验收录屏不超过 5 分钟。

对应场景：完整流程与重新开始。[官方验收说明](https://natalieagus.github.io/50033/docs/children/checkoff/)

### Lab 5

- SO 游戏架构，角色 FSM 的状态与转换复杂度对照课程示例。
- 独立 Buff 控制器，星星和 VIP 按秒到期。
- 展示状态切换音效、资源连接、全部重置、跨场景值保留。
- Hierarchy 中没有 DontDestroyOnLoad 区域，代码没有 Singleton。
- 验收录屏不超过 5 分钟。

对应场景：形态变化、受击闪烁、星星 / VIP 结束、完整重开。[官方验收说明](https://natalieagus.github.io/50033/docs/teen/checkoff/)、[课程状态机架构](https://natalieagus.github.io/50033/docs/teen/fsm/)

课程示例包含 Small、Super、Fire、受击短暂无敌和 Dead 五种角色状态；本方案将受伤保护按大小形态拆分，共六个状态，再加入独立 Buff 控制器。正式验收前，逐项对照原文与图中的转换，不能只靠状态数量判断合格。
